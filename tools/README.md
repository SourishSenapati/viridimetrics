# ViridiMetrics Core calculations Suite

ViridiMetrics calculations Suite is an enterprise-grade mathematical modeling engine and CLI application designed to quantify plant biomonitoring parameters, urban canopy filtration capabilities, occupational exposure hazards, and agricultural spray runoff. By utilizing empirical botanical attributes (such as cuticular wax density, stomatal parameters, and biochemical biomarkers), the system provides rigorous, verifiable data for municipal planners and ecotoxicologists.

The tools directory is organized into eight self-contained packages:

| Directory Name | Mathematical Module | Purpose & Scientific Context | Primary Equations & Outputs |
| :--- | :--- | :--- | :--- |
| **greenbelt-suitability-index** | APTI & API Classifier | Grades plant tolerance and suitability for highway or urban roadside greenbelts. | APTI Score, API Grade (1-16) |

## Mathematical Formulations

### 1. Air Pollution Tolerance Index & Anticipated Performance Classifier
*   **Air Pollution Tolerance Index (APTI):**
    $$\text{APTI} = \frac{A \cdot (T + P) + R}{10}$$
    Where $A$ is ascorbic acid ($\text{mg/g}$), $T$ is total chlorophyll ($\text{mg/g}$), $P$ is leaf pH, and $R$ is relative water content ($\%$).
*   **Anticipated Performance Index (API):**
    Combines APTI score categories (max 8 points), growth habit (dense tree: 4 points, open tree: 2 points, shrub: 1 point), seasonality (evergreen: 2 points, deciduous: 1 point), and socioeconomic value (high: 2 points, moderate: 1 point) to compute a score out of 16.

### 2. Trace Metal Translocation & Dietary Exposure Risk
*   **Translocation Factor (TF):**
    $$\text{TF} = \frac{C_{\text{plant}}}{C_{\text{soil}}}$$
*   **Daily Intake of Metal (DIM):**
    $$\text{DIM} = \frac{C_{\text{leaf}} \cdot W_{\text{leaf}} \cdot E_{\text{fraction}} \cdot V_{\text{intake}}}{V_{\text{water}} \cdot \text{BW}}$$
    Where $C_{\text{leaf}}$ is leaf metal concentration ($\text{mg/kg}$), $W_{\text{leaf}}$ is steep weight ($\text{kg}$), $E_{\text{fraction}}$ is water extraction rate ($\%$), $V_{\text{intake}}$ is daily consumed volume ($\text{L}$), $V_{\text{water}}$ is cup volume ($\text{L}$), and $\text{BW}$ is consumer body weight ($\text{kg}$).
*   **Hazard Quotient (HQ):**
    $$\text{HQ} = \frac{\text{DIM}}{\text{RfD}}$$
    Where $\text{RfD}$ represents US EPA Oral Reference Doses (Lead: 0.0035, Cadmium: 0.0005, Chromium: 0.0030, Nickel: 0.0200, Copper: 0.0400, Zinc: 0.3000).

### 3. Dry Deposition Velocity & Plume Mitigation
*   **Deposition Velocity ($V_d$):**
    $$V_d = V_{d,\text{base}} \cdot \text{LAI} \cdot \left(\frac{u}{2.0}\right) \cdot (1 + f_{\text{pubescent}})$$
    Capped at $6.0\ \text{cm/s}$ for $PM_{10}$, $2.5\ \text{cm/s}$ for $PM_{2.5}$, and $1.0\ \text{cm/s}$ for $PM_{0.2}$.
*   **Downwind Plume Concentration Decay:**
    $$C_{\text{downwind}} = C_{\text{ambient}} \cdot e^{-\frac{V_d \cdot \text{LAI} \cdot W}{H \cdot u}}$$
    Where $W$ is greenbelt width ($\text{m}$), $u$ is wind speed ($\text{m/s}$), and $H = 10\ \text{m}$ is mixing height.

### 4. Skin Dermal Partition & Exposure Modeler
*   **Skin-Air Partition Coefficient:**
    $$K_{\text{skin-air}} = 10^{(0.7 \cdot \log K_{\text{ow}} - 1.5)}$$
*   **Equilibrium Concentration Capacity:**
    $$M_{\text{eq}} = C_{\text{air}} \cdot V_{\text{skin-lipid}} \cdot K_{\text{skin-air}}$$
*   **Absorbed Dose Over Time:**
    $$M_{\text{absorbed}} = M_{\text{eq}} \cdot (1 - e^{-k_{\text{absorb}} \cdot t})$$

## Shared Database and Integration

*   **Master Database (`open_source_data.json`):** Contains validated plant profiles, physiological metrics, and heavy metal concentrations compiled from Jadavpur University, Sæbø, and Leonard empirical datasets.
*   **Calculations Integration (`engine.js`):** Instantiates the classes from each subfolder and maps CLI parameters to execution inputs.
*   **Central CLI (`cli.js`):** Integrates command parsing, interactive menu navigation, and batch mode calculations.

## Installation & Execution

### Setup
Ensure Node.js >= 18.0.0 is installed, then run:
```bash
npm install
```

### Run Interactive Console
```bash
npm start
```

### Run Batch Queries
To run queries directly from the command-line, provide the tool folder name (Archetype C) and arguments:
```bash
# Calculate greenbelt index for Ficus Religiosa
node cli.js --tool greenbelt-suitability-index --species ficus_religiosa

# Simulate pesticide spray retention on Morus Alba
node cli.js --tool pesticide-spray-retention --species morus_alba --rain 10 --adjuvant sticker
```

### Run Tests
To execute all modular tests consecutively:
```bash
npm test
```
