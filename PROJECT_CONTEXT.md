You are building Viridimetrics.

Viridimetrics is a commercial building analytics platform that estimates cooling load reduction generated by exterior green walls.

Target users:
- Facility Managers
- Sustainability Directors
- Commercial Real Estate Operators

Core value proposition:
Convert green walls from decorative ESG assets into measurable cooling infrastructure.

MVP Goal:
Estimate daily HVAC energy savings from a green wall using deterministic thermodynamic equations.

The MVP is NOT an IoT platform.
The MVP is NOT a digital twin.
The MVP is NOT a machine learning platform.

Inputs:
- Wall Area (m²)
- Plant Type
- Ambient Temperature
- Relative Humidity
- Solar Radiation

Output:
- Estimated Cooling Effect (kWh/day)
- Estimated Cost Savings ($/day)
- Estimated CO2 Reduction

Technical Constraints:
- Deterministic only
- Explainable calculations
- No black-box AI
- Use ASHRAE-style engineering assumptions

Stack:
- Next.js 15
- TypeScript
- Tailwind
- Python FastAPI
- PostgreSQL

Design:
- Apple-inspired
- Glassmorphism
- Minimal controls
- One primary output card

Always optimize for simplicity.
